# 📚 Sistema de Gestión de Biblioteca

Este proyecto es una aplicación web que permite gestionar información relacionada con **autores**, **libros**, **editoriales** y **préstamos**. Está diseñado utilizando **Bootstrap 5** para una interfaz moderna y responsiva, y es ideal para bibliotecas pequeñas o medianas que desean mantener su inventario y préstamos de forma organizada.

---

## 🧰 Tecnologías Utilizadas

- **HTML5** + **Bootstrap 5** (UI responsiva)
- **JavaScript** (eventos y lógica interactiva)
- (Opcional según avance: Blazor, ASP.NET Core, Entity Framework Core, SQL Server)

---

## 📁 Estructura de Navegación

El sistema se organiza en pestañas para cada entidad principal:

- `📖 Libro`
- `👤 Autor`
- `🏢 Editorial`
- `🔄 Préstamos`

Cada pestaña permite ver y editar información, con formularios y tarjetas detalladas para cada elemento.

---

## ✅ Funcionalidades

### Autor
- Mostrar y editar datos del autor: nombre, fecha de nacimiento/fallecimiento, nacionalidad, biografía.
- Lista de autores destacados (interactiva).

### Libro *(por implementar o extender)*
- Detalles del libro: título, autor, ISBN, año de publicación, editorial.
- Asignación de autor/editorial.

### Editorial *(por implementar o extender)*
- Listado y detalle de editoriales.
- Asociación con libros publicados.

### Préstamos *(por implementar o extender)*
- Registro de libros prestados y devueltos.
- Asociación con usuarios/lectores.
